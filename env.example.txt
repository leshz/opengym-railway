# openGym — configuration reference.
#
# On Railway you normally set NONE of these by hand: the template wires RP_ID and ORIGIN
# to your service's domain, and everything else has a working default. This file documents
# every knob, and doubles as the config for running the image locally.
#
# (Named env.example.txt rather than .env.example so it is unambiguously documentation.)

# --- WebAuthn identity (the settings that really matter) --------------------------------
# Passkeys are bound to an exact hostname and require HTTPS (http://localhost is the one
# exception browsers make). RP_ID is the bare hostname; ORIGIN is the full URL with scheme.
#
# WARNING: changing RP_ID after people have registered INVALIDATES their existing passkeys
#          and locks them out. Decide your final domain before anyone signs up.
#
# Railway template values:
#   RP_ID=${{RAILWAY_PUBLIC_DOMAIN}}
#   ORIGIN=https://${{RAILWAY_PUBLIC_DOMAIN}}
RP_ID=localhost
ORIGIN=http://localhost:8080

# Name shown in the browser's passkey prompt.
RP_NAME=openGym

# --- Storage -----------------------------------------------------------------------------
# Accounts, passkeys, workout history, the session secret and the VAPID keys all live here.
# On Railway this MUST be a mounted volume, or every redeploy wipes it.
DATA_DIR=/data

# --- Access control (both optional, default open) ----------------------------------------
# Comma-separated user ids that get the admin dashboard. Register your passkey first, then
# find your id in $DATA_DIR/db.json under users[].id.
ADMIN_UIDS=

# Set to 1 to require an invite code for new profiles. Existing accounts keep working.
INVITE_ONLY=0

# --- Sessions ----------------------------------------------------------------------------
# How long a signed-in session lasts. The expiry is baked into each cookie when issued, so
# lowering this never cuts existing sessions short.
SESSION_DAYS=90

# --- Push notifications -------------------------------------------------------------------
# VAPID keys are generated automatically on first run and stored on the volume. This is only
# the contact subject; it defaults to ORIGIN when served over HTTPS.
# VAPID_SUBJECT=mailto:you@example.com

# Remove the "Continue without account" button (guest mode). Default on.
# ALLOW_GUEST=0

# --- Activity log -------------------------------------------------------------------------
# Admin-dashboard activity log in $DATA_DIR/audit.log. On by default.
# AUDIT_LOG=0          # turn it off
# AUDIT_MAX=5000       # events kept (0 = no cap)
# AUDIT_DAYS=90        # days kept (0 = no cap)
# AUDIT_IP=off         # off | net | full — record client IP addresses

# Only when Cloudflare is really in front: let its client-IP header through.
# CF_CONNECTING_IP=$http_cf_connecting_ip

# Upload body limit for /api/media/ (nginx syntax). Keep it above upstream's
# MEDIA_VIDEO_MAX_MB (40 by default).
# MEDIA_UPLOAD_MAX=48m

# --- AI Coach -----------------------------------------------------------------------------
# Off until an admin enables it in Settings. This image is upstream's "default" target (no
# Agent SDK / Codex runtime); HTTP providers (Anthropic, OpenAI, Gemini, Ollama…) still work.
# COACH_DISABLED=1     # kill switch that outranks the admin toggle

# --- Upstream version (build time) --------------------------------------------------------
# Which openGym release to build. "latest" (default) = newest stable vX.Y.Z tag of
# DuarteSantos8/openGym. Set a tag such as v1.3.7 to pin or roll back, then redeploy.
# UPSTREAM_REF=latest

# --- Local only -----------------------------------------------------------------------------
# The port nginx listens on. Railway injects this automatically — do not set it there.
PORT=8080
